# 🏏 Virat Kohli Performance Analysis Dashboard \| Power BI

## 📌 Project Overview

An interactive **Virat Kohli Performance Analysis Dashboard** built
using Microsoft Power BI to explore and analyze Virat Kohli's cricketing
career and batting performance.

The dashboard presents insights into his overall career statistics, runs
scored against different teams, year-wise performance, match
distribution, and top-performing stadiums through visualizations.

## 🛠️ Tools & Technologies

-   Microsoft Power BI
-   Power Query
-   DAX (Data Analysis Expressions)
-   Data Cleaning & Transformation
-   Data Visualization

## 📊 Key Performance Indicators (KPIs)

-   **Total Matches:** 516
-   **Total Runs:** 24K
-   **Batting Average:** 45.95
-   **Centuries (100s):** 77
-   **Half-Centuries (50s):** 129
-   **Highest Score:** 254

## 📈 Dashboard Features

### 1. Overall Performance Analysis

-   Total matches played
-   Total runs scored
-   Batting average
-   Centuries and half-centuries
-   Highest individual score

### 2. Team-wise Performance

-   Runs scored against different teams
-   Top 5 teams based on matches played
-   Comparative team-wise analysis

### 3. Year-wise Performance

-   Runs scored across different years
-   Visual analysis of yearly performance trends

### 4. Stadium-wise Performance

-   Top 5 stadiums based on total runs scored
-   Stadium-wise performance comparison

## 🎯 Project Objectives

-   Analyze Virat Kohli's overall cricketing performance.
-   Identify teams against which he has scored the most runs.
-   Explore year-wise batting performance.
-   Identify his top-performing cricket stadiums.
-   Present cricket statistics through clear and meaningful
    visualizations.
